# Unity AI

## 项目简介

这是一个基于 Unity 和 C# 开发的 AI 聊天交互项目，支持文本对话、语音识别、语音合成及聊天历史管理。项目集成了多种 AI 服务，并结合 Unity UI 实现聊天交互界面，探索 AI 对话与游戏应用的结合。

## 主要功能

- **AI 文本聊天：** 支持接入 Ollama 本地大模型和智谱 AI，实现文本对话。
- **语音识别：** 接入讯飞语音识别（STT），将用户语音转换为文字。
- **语音合成：** 接入讯飞语音合成（TTS），将 AI 回复转换为语音播放。
- **聊天历史管理：** 支持聊天记录的本地保存、读取及历史会话管理。
- **角色与分类管理：** 支持角色配置、分类管理及角色名称翻译。
- **多语言支持：** 使用 Unity Localization 实现界面本地化。
- **激励广告：** 集成 Unity LevelPlay 激励视频广告，用于奖励额外的消息使用次数。


## 运行说明

1. 使用 Unity Hub 打开项目。
2. 等待 Unity 完成项目资源导入。
3. 根据需要配置 Ollama、智谱 AI 和讯飞语音服务。
4. 检查相关服务地址及本地配置文件。
5. 运行项目场景，体验 AI 聊天与语音交互功能。

项目使用的 AI 和语音服务可能需要相应的密钥及服务配置。请根据项目中的配置脚本和实际使用的服务完成设置。

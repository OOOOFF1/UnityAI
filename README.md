# Unity AI聊天交互客户端
## 项目简介
基于 Unity + C# 开发的移动端AI聊天交互应用，实现文本对话、语音识别与语音朗读，搭配本地化UI与激励广告系统。项目整合本地大模型Ollama与智谱云大模型，探索AI对话能力在游戏/交互客户端中的落地。

## 主要功能
- **AI文本对话**：支持Ollama本地大模型、智谱AI在线大模型双后端文本对话。
- **语音识别 STT**：集成讯飞语音识别，麦克风输入转文字。
- **语音合成 TTS**：集成讯飞语音合成，AI文本回复转为语音播放。
- **聊天会话管理**：本地持久化保存聊天记录，支持多会话创建、读取与切换。
- **角色管理**：自定义对话角色配置，支持角色信息与名称翻译。
- **多语言本地化**：使用Unity Localization包，实现UI界面多语言切换。
- **激励广告系统**：接入Unity LevelPlay激励视频广告，观看广告获取额外对话次数。

## 注意事项
- Ollama模式：本地电脑必须安装并启动Ollama服务，并且提前下载对应模型。
- 智谱AI、讯飞语音：需要自行申请API Key，接口能力受网络、账号额度限制。
- 广告功能：激励广告SDK在Windows平台无法正常展示，广告仅Android打包版本生效。

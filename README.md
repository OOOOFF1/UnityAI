# Unity 2D 像素风横版平台跳跃游戏

## 游戏简介

使用 Unity 和 C# 独立开发的 2D 像素风横版平台跳跃游戏。玩家可以移动、跳跃、冲刺、使用武器攻击敌人，并体验 NPC 对话、关卡挑战与进度存档等功能。

## 游戏操作

| 操作 | 按键 |
|---|---|
| 左右移动 | A / D |
| 跳跃、二段跳 | 空格键 |
| 冲刺 | Left Shift |
| 射击 | 鼠标左键 |
| 切换武器显示 | 鼠标右键 |
| 与 NPC 对话 | F |
| 打开暂停菜单 | Esc |

## 核心功能

- 角色移动、跳跃、二段跳与冲刺
- 武器射击、敌人交互和道具收集
- NPC 对话与多关卡流程
- 关卡选择、解锁、通关与重试
- JSON 存档与玩家进度恢复
- EventBus 事件解耦与对象池
- Unity Editor 场景对象 ID 批量分配工具

## 技术栈

Unity、C#、UGUI、Rigidbody2D、Cinemachine、JSON、Unity Editor API。
